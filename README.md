# CartesianRobotSim
Task:
Make a program that simulates a Cartesian robot (X,Y,Z).
Each axis can be jogged around or given an absolute command.
A list of positions can be taught.
The robot can follow taught positions.
Bonus:
GUI has pop-out windows and window docking.
Technologies:
C#
WPF (Windows Presentation Foundation)
MVVM (Model-View-ViewModel)
Microsoft Visual Studio
OOP Basics
Threads
Events
